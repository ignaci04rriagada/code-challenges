# 🧩 Code Challenges & Practicas

¡Hola! 👋 En este repo voy guardando la resolución de distintos retos de código, ejercicios y experimentos que voy haciendo para soltar la mano, practicar lógica y probar buenas prácticas de desarrollo.

La idea no es solo que el código funcione, sino también aprender sobre arquitectura, patrones de diseño y escribir código cada vez más limpio.

---

## 🛠️ ¿Qué tecnologías uso por acá?

Principalmente **JavaScript (Vanilla)** y **PHP**, junto con **MySQL** para los temas de bases de datos.

---

## 📌 ¿Cómo está organizado esto?

Cada reto tiene su propia carpeta con el código organizado y un `README.md` individual donde explico en detalle qué pedía el desafío, cómo lo resolví y cómo ejecutarlo.

*A medida que vaya haciendo más retos de otras plataformas o comunidades, los iré sumando aquí.* 💻✨
